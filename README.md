# JavaScript Games

This repository contains a collection of simple browser games made with HTML, CSS, and JavaScript. Each game is placed in its own folder and can run directly in the browser.

## How To Run

1. Clone or download the repository.
2. Open any game folder.
3. Open that folder's `index.html` file in your browser.

No installation or extra setup is needed.

## Games Included

### 1. Click Counter
Folder: `Click Counter`

How to play:
- Press `Click Me` to increase the counter.
- Press `Minus` to decrease the counter.
- Press `Reset` to set the counter back to zero.

### 2. Color Guess
Folder: `Color Guess`

How to play:
- Read the RGB color value shown on the screen.
- Click the color tile that matches that RGB value.
- Press `New Round` to generate a fresh set of colors.

### 3. Whack-a-Mole
Folder: `Whack-a-Mole`

How to play:
- Press `Start Game` to begin.
- Click the mole as it appears in different holes.
- Score as many points as possible before the timer ends.

### 4. Memory Card
Folder: `Memory Card`

How to play:
- Click two cards to flip them.
- Match both cards with the same symbol.
- Match all pairs to win the game.

### 5. Tic-Tac-Toe
Folder: `Tic-Tac-Toe`

How to play:
- Two players take turns as `X` and `O`.
- Click an empty box to place your mark.
- Complete a row, column, or diagonal to win.

### 6. Rock Paper Scissors
Folder: `Rock Paper Scissors`

How to play:
- Choose `Rock`, `Paper`, or `Scissors`.
- The computer will choose its move automatically.
- The score updates after every round.

### 7. Number Guess
Folder: `Number Guess`

How to play:
- Guess the hidden number between 1 and 100.
- Enter your guess and press `Guess`.
- Use the hints to reach the correct number before attempts run out.

### 8. Hangman
Folder: `Hangman`

How to play:
- Guess the hidden word one letter at a time.
- Click letters from the on-screen keyboard.
- Win by revealing the full word before your wrong guesses run out.

### 9. Simon Says
Folder: `Simon Says`

How to play:
- Press `Start Game`.
- Watch the color sequence carefully.
- Repeat the same pattern in the correct order.

### 10. 2048 Lite
Folder: `2048 Lite`

How to play:
- Use the arrow keys on your keyboard to move all tiles.
- Match the same numbers to merge them into larger values.
- Keep combining tiles until you reach `2048`.
